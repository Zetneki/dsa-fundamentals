# Linked List

## What is a Linked List?

## Structure

A node contains:

- value
- pointer/reference to the next node

## Types

- Singly Linked List
- Doubly Linked List
- Circular Linked List

## Operations

- Access
- Search
- Insert
- Delete
- Traverse
- Reverse

## Time Complexity

| Operation      | Singly |
| -------------- | ------ |
| Access         | O(n)   |
| Search         | O(n)   |
| Insert at head | O(1)   |
| Delete at head | O(1)   |
